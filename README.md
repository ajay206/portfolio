# Ajay Kumar Kondeti

Personal portfolio, published with GitHub Pages at <https://ajay206.github.io/portfolio/>.

## Content

All page copy lives in [`content.json`](content.json). `build.py` generates the site from that file. Edit the data file, not the generated HTML.

Highlight cards repeat figures that already appear in the experience bullets. Each highlight has a `source` string, and the build fails if that string is not in the bullets.

## Build locally

```bash
python3 -m pip install -r requirements.txt
python3 build.py
python3 -m http.server -d dist 8080
```

Open <http://127.0.0.1:8080/>.

## Update the resume

1. Replace `assets/Ajay_Kumar_Kondeti_Resume.pdf` with the new public PDF. Do not include a phone number.
2. Update the matching fields in `content.json` (summary, experience, skills, projects, highlights, contact).
3. Push to `main`.

GitHub Actions builds the site and deploys the `dist/` folder to GitHub Pages. In the repository settings, Pages → Build and deployment → Source must be **GitHub Actions**.

## Stack

Plain HTML and CSS generated by Python. Inter and Space Grotesk are self-hosted Latin subsets (`font-display: swap`); both are under the SIL Open Font License (`fonts/inter-OFL.txt`, `fonts/space-grotesk-OFL.txt`). Motion is a short inline script and is skipped when the visitor prefers reduced motion.
